# Ресурсы для «Осеннего двора»

Готовые исходные файлы для подключения к существующей игре. Игра в этом архиве не содержится. Результат после подключения и производительность в Safari пока не проверены.

## Модели

Quaternius, Stylized Nature MegaKit Standard, CC0. Оригинальная лицензия приложена.

- models/CommonTree_1.gltf — дерево, 6265 треугольников.
- models/CommonTree_3.gltf — второе дерево, 3505 треугольников.
- models/Bush_Common.gltf — куст, 900 треугольников. Можно повторять группами вдоль ограждения; это не отдельная модель стриженой изгороди.

Рядом находятся необходимые .bin и текстуры. Переносить папку models целиком, не переименовывать зависимости. Использовать GLTFLoader той же версии, что и Three.js в игре; зависимости загрузчика тоже сохранить локально.

Оригинальная листва зелёная. autumn-foliage.js — небольшой адаптер материала для золотистой осенней окраски, без изменения исходных картинок. Он применяет оттенок только к материалам Leaves; кору не затрагивает и прозрачность сохраняет. Это подготовленный код, ещё не проверенный в сцене игры: после подключения проверить компиляцию шейдера и внешний вид. Пример: applyAutumnFoliage(model.scene, THREE, '#c58b32'). Для второго дерева можно взять '#bc6c2f'. Куст оставить зелёным или использовать приглушённую охру.

Модели идут без фирменных шейдеров демонстрационной сцены автора. Не обещать идентичный вид рекламному превью: свет и материалы надо настроить в игре.

## Материалы

В каждой папке три карты 1K: color.jpg (sRGB), normal.jpg (OpenGL, без цветового преобразования), roughness.jpg (данные, без цветового преобразования).

- oak_wood_planks — забор, деревянные детали.
- white_plaster_02 — штукатурка дома.
- stone_wall — каменная стена/цоколь. Для отдельных плит дорожки не использовать рисунок кладки.
- grey_roof_tiles — серая черепица.
- grass_ground — основание газона; убрать старые чёрные пучки травы.

Использовать MeshStandardMaterial; normalMap задаёт визуальный рельеф, геометрический displacement не включать. Для крупного двора применять повторение текстур с масштабом по реальным размерам рисунка. Подобрать умеренный normalScale: старт 0.2–0.4 для штукатурки и газона, 0.4–0.7 для камня и дерева. Это ориентиры, нужна визуальная настройка. Фотографические текстуры могут потребовать приглушения детализации, чтобы сочетаться со стилизованными моделями.

## Задание Клоду

1. Подключи эти ресурсы в основной игровой двор с сохранением и магазином.
2. Замени зелёные глыбы деревьями: сначала 2–4 дерева и небольшая группа кустов, не густой лес. Нормализуй высоту деревьев примерно до 4–6 м, кустов до 0.6–1.1 м после измерения bounding box.
3. Закрой пустой горизонт ограждениями и растительностью. Не меняй коллизии и места доступных листьев без необходимости.
4. Примени материалы к дому, ограде, каменной стене, крыше и земле. Сохрани спокойную осеннюю палитру, настрой мягкий тёплый свет.
5. Сохрани сбор кликом, покупки, экономику и сохранения. Ходьба не должна расчищать дорожки в листьях.
6. Не добавляй в сцену все модели/текстуры в высоком разрешении и не размножай материалы для каждого объекта. Начни с небольшого количества экземпляров. Проверь кадры с растительностью, ошибки загрузки и прозрачности, а также FPS.
7. Дай запускаемую сборку и список изменений. Долгую съёмку видео не запускай. Не заявляй проверку Safari, если тестировал в другом браузере.
